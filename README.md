# 3D rekonstrukcija objekata

Ovaj repozitorij sadrži programski kod za sustav 3D rekonstrukcije objekata pomoću laserske stereo kamere Zebra AltiZ i robotske ruke Universal Robots.

Kod omogućuje dohvaćanje 3D linijskih profila s kamere, komunikaciju s robotskom rukom, sinkronizaciju podataka te spremanje i vizualizaciju rezultata.

## Tehnologije

- C++
- Python
- Zebra AltiZ API
- Matrox Imaging Library SDK
- TCP/IP komunikacija

## Namjena

Projekt je izrađen u sklopu završnog rada na Fakultetu strojarstva i brodogradnje Sveučilišta u Zagrebu.
